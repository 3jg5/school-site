# موقع مدرسة الفاروق — دليل التشغيل والتسليم

موقع رسمي باللغة العربية (RTL) لمدرسة الفاروق، يشمل الصفحة الرئيسية، المكتبة الإلكترونية، ولوحة الإدارة، مع تخزين سحابي حقيقي عبر **Firebase Firestore** ومصادقة عبر **Firebase Authentication**. تعرض المكتبة ملفات مجلد الدرايف الرسمي **داخل الموقع نفسه** كبطاقات تشبه الأخبار مع صورة ووصف وتصنيف ومعاينة مباشرة، وتمكّن الإدارة من **رفع الملفات وتعديلها وحذفها من داخل الموقع** بعد ربط حساب Google.

**المطوّر:** علي محمد الرحمة — Ali Mohammed Al Rahma

---

## التشغيل

- انقر نقراً مزدوجاً على `start-site.bat`، ثم انتظر فتح المتصفح تلقائياً على:
  `http://localhost:8123/index.html`
- يتطلب تشغيل الملف وجود **Python** على الجهاز (لأمر `python -m http.server`).
- الصفحات:
  - [index.html](index.html) — الصفحة الرئيسية
  - [library.html](library.html) — المكتبة الإلكترونية
  - [admin.html](admin.html) — لوحة الإدارة

### سلوك الدخول

- **الوضع السحابي (الحالي):** الدخول ببريد وكلمة مرور حساب الإدارة `mahmoud@school.com` من [admin.html](admin.html). لا توجد صفحة تسجيل عامة.
- **الوضع التجريبي:** يعمل تلقائياً فقط إذا أُزيل `firebaseConfig` من [js/config.js](js/config.js) أو تعذّر تحميل Firebase. كلمة المرور التجريبية `farooq2026` للعرض المحلي فقط، وبياناته مؤقتة ولا تُخزَّن سحابياً.

تسجيل الدخول يبقى محفوظاً في المتصفح حتى تسجيل الخروج.

### تغيير كلمة المرور أو إنشاء حساب إدارة جديد

1. افتح `console.firebase.google.com` واختر مشروع **Al-Farooq School**.
2. **Authentication ← Users**.
3. لإعادة تعيين كلمة المرور: قائمة الحساب ← **Reset password**، أو استخدم **Add user** لإنشاء حساب جديد.
4. عند إنشاء حساب جديد، حدّث معرّف المستخدم (UID) داخل الدالة `isEditor()` في [firestore.rules](firestore.rules)، ثم أعد نشر القواعد من **Firestore ← Rules**.

## المكتبة الإلكترونية ومجلد الدرايف

- مجلد المكتبة الرسمي: `1dKSMPTkD43ZEgsJNzqumd26A1sS7YP_H` (مكتبة الفاروق الرقمية).
- يقرأ الموقع محتويات المجلد عبر **Google Drive API v3** باستخدام مفتاح المتصفح في `driveApiKey` داخل [js/config.js](js/config.js)، ثم يعرض الملفات كبطاقات داخل الصفحة.
- يمكن التنقل بين المجلدات الفرعية، والبحث في الملفات، وتحديث المحتوى دون مغادرة الصفحة.
- معاينة ملفات PDF والصور والوثائق تُفتح داخل نافذة معاينة في الموقع عبر `drive.google.com/file/d/{id}/preview`.
- عند تعذّر الاتصال بـ Drive API يظهر بديل مضمّن للمجلد الرسمي، فلا تتحول المكتبة إلى رابط خارجي.
- رابط المجلد قابل للتغيير من **لوحة الإدارة ← إعدادات البوابة**، وتُحدَّث الواجهة تلقائياً بعد الحفظ وإعادة تحميل المكتبة.

### مفتاح Drive API

- المفتاح الحالي مقيّد بـ **Google Drive API** فقط، وبعناوين المرجع (HTTP referrers) المسموح بها: `alfarooqom.com`، `farooq-school-site.web.app`، و`localhost:8123`.
- إذا نُشر الموقع على نطاق جديد أو بادئة `www`، أضِف العنوان إلى قيود المفتاح من:
  `console.cloud.google.com/apis/credentials` ← اختر مفتاح Drive ← **HTTP referrers**.
- المجلد يجب أن يكون مشاركاً بصلاحية **أي شخص لديه الرابط** حتى تظهر الملفات للزوار.

### إدارة المكتبة من لوحة الإدارة

- **مكتبة الدرايف** في لوحة الإدارة تعرض ملفات المجلد نفسه مع الوصف والتصنيف، وتتيح:
  - تعديل العنوان الظاهر والوصف والتصنيف لأي ملف أو مجلد.
  - رفع ملف واحد أو عدة ملفات مع شريط تقدّم، وإنشاء مجلدات فرعية.
  - تعديل الاسم الفعلي للملف في الدرايف، وحذف الملفات أو المجلدات (الحذف يشمل محتويات المجلد الفرعي).
- مشاهدة الملفات وتعديل أوصافها تعمل بعد تسجيل الدخول إلى لوحة الإدارة، **دون** الحاجة إلى ربط Google.
- الرفع والإنشاء وتغيير الاسم والحذف تتطلب **ربط حساب Google** مرة واحدة من زر «ربط حساب Google». تُحفظ جلسة الوصول في ذاكرة المتصفح فقط وتنتهي تلقائياً بعد نحو ساعة أو عند تسجيل الخروج.
- الأوصاف والعناوين والتصنيفات تُخزَّن داخل مستند `settings/site` في حقل `library`، لذلك لا تحتاج إلى مجموعة Firestore جديدة أو تعديل قواعد الأمان.
- الحساب المستخدم في الربط يجب أن يملك صلاحية **تعديل** على مجلد المكتبة (المشاركة «أي شخص لديه الرابط» تسمح بالقراءة فقط). الملفات المرفوعة تُحتسب على مساحة تخزين Google Drive لذلك الحساب.

### تفعيل معرّف OAuth مرة واحدة

1. افتح `console.cloud.google.com/apis/credentials?project=farooq-school-site` بنفس حساب Google المسؤول.
2. من **OAuth consent screen** (أو Google Auth Platform) أكمل بيانات التطبيق: اسم «مدرسة الفاروق»، بريد الدعم، والبريد الإلكتروني للمطوّر.
3. أضف النطاق `https://www.googleapis.com/auth/drive` ضمن **Scopes**. إذا كان نوع التطبيق **External / Testing**، أضف بريد الإدارة `mahmoud@school.com` ضمن **Test users**.
4. من **Create credentials ← OAuth client ID** اختر النوع **Web application**، ثم أضف في **Authorized JavaScript origins**:
   - `http://localhost:8123` للتجربة المحلية.
   - نطاق Vercel النهائي، مثل `https://your-project.vercel.app` (بدون مسار أو شرطة مائلة).
   - `https://alfarooqom.com` و`https://www.alfarooqom.com` فقط إذا سيرتبط الموقع بهذا النطاق.
5. انسخ **Client ID** الظاهر بعد الإنشاء (ينتهي بـ `.apps.googleusercontent.com`).
6. من لوحة الإدارة ← **إعدادات البوابة** الصقه في حقل «معرّف OAuth لربط الدرايف» ثم اضغط **حفظ الإعدادات**.
7. من تبويب **مكتبة الدرايف** اضغط **ربط حساب Google** واختر الحساب الذي يملك صلاحية التعديل على المجلد.

> لا تضع كلمة مرور Google أو أي سر داخل ملفات المشروع. معرّف OAuth (Client ID) ليس سراً، لكنه مرتبط بالنطاقات المصرّح لها أعلاه.
>
> إذا ظهرت شاشة «Google hasn’t verified this app» فاختر **Advanced** ثم المتابعة؛ التطبيق للاستخدام الداخلي للمدرسة وليس تطبيقاً عاماً.

### استضافة Vercel

- الموقع ثابت (HTML/CSS/JS) ولا يحتاج أمر بناء. يكفي نشر مجلد المشروع كما هو.
- من داخل مجلد المشروع يمكن النشر عبر:
  `npx vercel login` ثم `npx vercel --prod` (أو استلام النشر المؤقت من رابط Vercel المرفق بالتسليم).
- التحديثات اللاحقة: أعد تنفيذ `npx vercel --prod` بعد تعديل الملفات.
- بعد تثبيت النشر على حساب Vercel، أضف نطاق Vercel النهائي إلى:
  1. **Firebase ← Authentication ← Settings ← Authorized domains** حتى يعمل تسجيل الدخول.
  2. **Google Cloud ← مفتاح Drive API ← HTTP referrers** حتى تُقرأ ملفات المكتبة.
  3. **OAuth Client ← Authorized JavaScript origins** حتى يعمل زر ربط الدرايف.
- أي نطاق مخصص جديد (مثل `alfarooqom.com`) يحتاج التعديلات الثلاثة نفسها.

## بنية البيانات في Firestore

| المجموعة | الحقول |
|---|---|
| `news` | `title`, `category`, `summary`, `body`, `date`, `image`, `pinned`, `createdAt`, `updatedAt` |
| `announcements` | `title`, `body`, `date`, `link`, `createdAt`, `updatedAt` |
| `settings` | مستند `site` يحتوي `instagram`, `twitter`, `libraryDrive`, `driveClientId`, `library`, `updatedAt` |

حقل `library` داخل مستند `settings/site` هو مصفوفة أوصاف ملفات الدرايف، وكل عنصر يحتوي:
`id` (معرّف ملف الدرايف)، `title`، `description`، `category`، `updatedAt`.

الصور تُضغط داخل المتصفح وتُحفظ كـ Data URL داخل مستند الخبر، لذا لا حاجة إلى Firebase Storage حالياً.
