# ملخص مشروع موقع مدرسة الفاروق

آخر تحديث: 2026-10-26

## ما هو الموقع

موقع رسمي عربي (RTL) من ثلاث صفحات، بدون أدوات بناء، يعمل على أي استضافة ثابتة:

| الصفحة | الوظيفة |
|---|---|
| `index.html` | الشعارات الثلاثة (التربية والتعليم، مدرسة الفاروق، رؤية عمان 2040)، بوابة المواقع، آخر الأخبار |
| `library.html` | المكتبة الإلكترونية: بطاقات لملفات الدرايف مع وصف وصورة مصغرة وبحث |
| `admin.html` | لوحة الإدارة: أخبار، إعلانات، ملفات المكتبة، إعدادات البوابة |

## ما تم إنجازه

- **الشعارات الرسمية الثلاثة** وصور أخبار في `assets/`.
- **بوابة الدخول** إلى موقع المدرسة `https://alfarooqom.com/` (روابط إنستغرام وتويتر تُضاف من لوحة الإدارة).
- **Firebase Firestore** للأخبار والإعلانات مع تحديث لحظي لجميع الزوار، و**Firebase Auth** لحماية لوحة الإدارة.
- **المكتبة الإلكترونية**: 18 عنصرًا من مجلد الدرايف تظهر داخل الموقع كبطاقات (عنوان، وصف، تصنيف، تاريخ، حجم، معاينة) بدل التحويل إلى درايف.
- **إدارة المكتبة من الموقع**: الإدارة تعدّل الوصف والتصنيف لأي ملف بدون Google، وبعد ربط حساب Google تستطيع **رفع ملفات، إنشاء مجلدات، إعادة تسمية، وحذف** مباشرة من لوحة الإدارة.
- **بيانات وصف الملفات** محفوظة داخل مستند `settings/site` في Firestore (حقل `library`)، لذلك لا حاجة لقواعد Firestore إضافية.
- **Vercel**: نُشر الموقع نشرًا تجريبيًا مؤقتًا بنجاح، وبانتظار الربط الدائم عبر GitHub.
- **ملفات التسليم**: مجلد واحد جاهز على سطح المكتب `school site`.

## الحساب الإداري

- البريد: `mahmoud@school.com`
- كلمة المرور: محفوظة لديك فقط، ولا توجد في أي ملف من ملفات المشروع.

## المتبقي لإكمال النشر

1. **رفع الملفات إلى GitHub** في المستودع `3jg5/school-site` (23 ملفًا).
   - البنية المطلوبة: أن يكون `index.html` في جذر المستودع، مع مجلدات `css/` و`js/` و`assets/`.
   - لا يُرفع: `.git` ولا `.vercel`.
2. **Vercel**: Add New ← Project ← Import المستودع ← Deploy.
   - Framework Preset: Other، واترك Build Command وOutput Directory فارغين.
3. **إضافة دومين Vercel النهائي** في ثلاثة أماكن:
   - Firebase Console ← Authentication ← Settings ← Authorized domains
   - Google Cloud ← مفتاح Drive API ← HTTP referrers
   - Google Cloud ← OAuth Client ← Authorized JavaScript origins
4. **إنشاء OAuth Client ID** (مرة واحدة): Consent screen + صلاحية Drive + Web application، ثم لصق المعرّف في:
   لوحة الإدارة ← إعدادات البوابة ← «معرّف OAuth لربط الدرايف» ← حفظ.
5. **اختبار فعلي**: تسجيل الدخول، رفع ملف، إعادة تسمية، إنشاء مجلد، حذف، والتأكد من ظهورها في المكتبة العامة.
6. **قبل الإطلاق**: استبدال الأخبار والإعلانات التجريبية بمحتوى حقيقي، إضافة روابط إنستغرام وتويتر، تغيير كلمة مرور الإدارة.

js/store.js         طبقة البيانات والمصادقة والتحديث اللحظي

js/home.js          منطق الصفحة الرئيسية
js/library.js       منطق المكتبة

## ملاحظات أمنية

- `js/config.js` يحتوي مفاتيح Firebase وDrive **العامة** (تعمل من المتصفح)، والحماية الفعلية من `firestore.rules` وصلاحيات Firebase.
- لا تُخزَّن كلمة مرور الإدارة في أي ملف.
- ربط Google للرفع والحذف يمنح رمز وصول مؤقتًا في ذاكرة المتصفح فقط، وينتهي خلال ساعة تقريبًا.
- ملفات الدرايف المحذوفة من الموقع تُحذف فعليًا من حساب Google، لذا يُنصح بمراجعة الحذف داخل نافذة التأكيد.
